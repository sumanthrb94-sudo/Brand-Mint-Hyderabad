# Screenshots of the work

Drop one image per project here, named by its `id` in `shared/work.js`:

    work/simplysip.jpg
    work/tresorcouture.jpg
    work/greenteam.jpg
    work/freshkart.jpg

**Specs:** 1600×1000 (16:10), JPG, under 300 KB each.

The easiest way to get a good one: open the site on a desktop browser at
1440px wide, screenshot the top of the home page, crop to 16:10. Show the
product, not the browser chrome — no address bar, no tabs.

A project with no image here still renders, as a typographic card. It just
does less work for you than a picture of the real thing.
