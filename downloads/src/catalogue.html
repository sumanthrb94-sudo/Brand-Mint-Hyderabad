Template

Product catalogue template

The exact fields we ask every client for before a single page is built. Fill one row per variant in a spreadsheet with these column names, and the build starts the day we receive it. A matching CSV is on the same download page.

01Columns, in order

ColumnWhat goes in itExample

titleProduct name as customers should see it. No SKU, no all-caps.Indigo Block-Print Kurta

02Photography spec

  • One consistent backgroundWhite or a single warm neutral, for every product. Consistency sells more than quality.
  • Square, at least 1600×1600 pixelsJPG or PNG. Name files by SKU: KURTA-BLU-M-1.jpg.
  • Front, back, one detail, one in useFour photos per product is the floor for conversion. Variants that differ only in colour need one photo each.

03Before you send it

  • Every SKU is unique and every variant has its own row
  • Prices include GST and the rate column matches your CA's list
  • Weights and dimensions are for the packed parcel, not the bare product
  • Photo file names match the image columns exactly
Timelines run from the day we receive your assets. A finished catalogue is the single biggest thing that keeps a build on schedule.
